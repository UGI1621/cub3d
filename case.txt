모든 테스트는

```c
valgrind --leak-check=full --track-fds=yes --show-leak-kinds=all
```

로 실행한다.

- 정상적인 map파일인지 확인하기 (에러 메세지 매칭되는지도 확인)
    - [ ]  `*.cub` 아닌파일
    - [ ]  `*.` 인 파일
    - [ ]  확장자 없는파일
    - [ ]  `*.cub` 인 directory
    - [ ]  `*.cub.cub` 파일
    - [ ]  권한없는파일
    - [ ]  빈파일
    - [ ]  개행만 있는 파일
    - [ ]  없는 파일
    - [ ]  요소별로 앞뒤로 공백이 있는 파일 <<< 가능해야함
    - [ ]  요소끼리 개행으로 구분이 안되어있는 파일 <<< 가능해야함
    - [ ]  `NO` , `SO` , `EA` , `WE` 가 여러번 정의되어 있는 파일
    - [ ]  `F` , `C` 가 여러번 정의되어 있는 파일
    - [ ]  `NO` , `SO` , `EA` , `WE` 중에 하나가 빠져있는 파일
    - [ ]  `F` , `C` 중에 하나가 빠져있는 파일
    - [ ]  필요없는 요소가 들어있는 파일
    - [ ]  서순 texture →map → fc
    - [ ]  서순 fc → map _ texture
    - [ ]  서순 map → texture → fc
    - [ ]  서순 map → fc → texture
    - [ ]  서순 mix → map <<< 성공해야함
    - [ ]  서순 map → mix <<< 실패해야함
    - [ ]  (`NO` , `SO` , `EA` , `WE` , `F`, `C`) 가 빠진파일
    - (`NO` , `SO` , `EA` , `WE`)가 오류인 파일
        - [ ]  `*.xpm` 아닌파일
        - [ ]  `*.` 인 파일
        - [ ]  확장자 없는파일
        - [ ]  `*.xpm` 인 directory
        - [ ]  권한없는파일
        - [ ]  빈파일
        - [ ]  개행만 있는 파일
        - [ ]  없는파일
        - 내부 정보가 잘못된 파일
            - [ ]  `cn` 과 정의된 픽셀색의 갯수가 다를 때
            - [ ]  헤더가 잘못되었을 때
            - [ ]  정의된 크기와 실제 픽셀의 크기가 다를 때
            - [ ]  색상코드 범위가 잘못되었을 때
            - [ ]  픽셀, 픽셀당 바이트 정보가 빠졌을 때
    - `F,C` 가 오류인 파일
        - [ ]  R,G,B 값 overflow underflow
        - [ ]  값의 개수가 3개가 아님
        - [ ]  값이 숫자가 아님
    - map이 오류인 파일
        - 벽으로 둘러쌓여있지 않은 파일
            - [ ]  윗쪽 벽이 뚫려있을때
            - [ ]  아랫쪽 벽이 뚫려있을 때
            - [ ]  왼쪽 벽이 뚫려있을 때
            - [ ]  오른쪽 벽이 뚫려있을 때
        - [ ]  유저의 위치가 없는 파일
        - [ ]  유저가 여러곳에 있는 파일
        - [ ]  인덱스 `0` 일때 값이 `0`인 경우

            ```
            01111111
            10000001
            11111111
            ```

        - [ ]  벽에 둘러쌓여있지만 벽중 한곳이 유저인 파일

            ```
            111S1111
            10000001
            11111111
            ```

        - [ ]  유저가 벽 밖에 있는 파일
        - [ ]  필요없는 요소가 들어있는 파일
        - [ ]  유저를 기준으로 아무런공백 없이 벽으로 둘러싸여 있는 파일
        - [ ]  둘러싸여있는 벽중 모서리가 없는 파일

        ```
         1
        1N1
         1
        ```
